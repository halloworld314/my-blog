欢迎来到我的新博客！

从今天起，这里就是「风和桥」——一个用 [Astro](https://astro.build) 和 [Fuwari](https://github.com/saicaca/fuwari) 主题搭建的小站。

## 写文章

在项目根目录运行：

```bash
pnpm new-post <文件名>
```

## 本地预览

```bash
pnpm dev
```

## 部署

构建产物输出到 `dist/` 目录，可直接部署到 Vercel、Netlify、GitHub Pages 等平台。
